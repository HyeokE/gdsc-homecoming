# 코드 리뷰와 단순화 — 2026-10-10

도메인 구조로 정리된 현재 작업 폴더를 기준으로 앱 라우팅, 발급·재발급, 저장·복원, 전광판·절취 UI, Firestore 규칙, 명단 가져오기, 배포 스크립트와 CI를 검토했다. 기존 디자인·동작과 공개 도메인 경계는 유지했다.

## 단순화

- 발급·재발급의 불확실한 응답 복구를 `runTicketOperation`으로 통합했다. 재시도 전 조회, 이미 저장된 결과의 재사용, 조회 실패 시 추가 쓰기 차단, 원래 불확실 오류 보존을 테스트한다.
- 정상 응답과 복구 응답 모두 `revealTicket`을 거쳐 화면·인원·저장 상태를 동일하게 초기화한다.
- 이미지 저장 4곳의 중복 클릭 잠금·상태·오래된 완료 응답 무효화를 `useTicketImageSave`로 통합했다.
- 두 발권 경로의 동일한 JSX를 하나로 사용하고, 사용되지 않던 `continueLabel` 전달을 제거했다.
- 전광판의 한 항목짜리 중첩 배열과 반복 `indexOf` 계산을 직접 순회로 교체했다.
- 통합 스토리의 오래된 안내·버튼 이름과 버튼 활성화 대기 조건을 현재 동작에 맞췄다.

## 검증 범위

검사·테스트 결과는 이번 수정의 로컬 검증이다. 운영 배포 및 실제 참가자 발급 검증과 구분한다. CodeRabbit은 회사 계정에 연결되어 있어 사용하지 않았으며, 소스 직접 검토와 독립 리뷰·테스트로 확인했다. 기존 이메일 지식 기반 접근, 브라우저 추첨의 조작 가능성은 이번 리팩터링에서 인증·추첨 정책으로 변경하지 않았다.
