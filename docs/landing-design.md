# 입장·입력 화면의 종이 티켓 콘셉트

최종 사용자 승인 기준은 `outputs/paper-ui-concept-v2.png`다. **검정 외부 배경과 따뜻한 흰색(`#faf9f6`) 종이 티켓 패널**로 입장·이메일·닉네임 화면을 연결한다. 앞선 사진 중심 랜딩과 정적 플립 제목 랜딩은 대체된 초안이며 현재 디자인 기준이 아니다.

## 공통 PaperTicket

`PaperTicket.tsx`는 세 화면의 상단·종이 표면·하단 문의를 공유한다. 상단은 실제 탑승권의 `AirlineBrand` 컴포넌트와 같은 Google 4색 마크·`GDGoC DJU`를 사용하고, 반대쪽에 작은 고정폭 `HOMECOMING 2026`을 표시한다. 점선 절취선과 양옆 원형 홈은 장식이며 보조기술에서 숨긴다.

큰 영문은 자체 호스팅 **Anton normal 400**을 사용한다. 응축된 굵은 sans 외형이며 serif·stencil 서체나 합성 bold를 사용하지 않는다. `HOME / COMING`, `CHECK-IN`, `PASSENGER`에 적용하고, 작은 메타데이터·날짜·입력값은 시스템 고정폭 글꼴, 한국어 내용은 시스템 sans로 유지한다. 공식 Google Fonts에서 받은 Latin WOFF2와 SIL OFL 1.1 출처는 `docs/licenses/anton.md`와 `anton-OFL.txt`에 기록되어 있다.

종이 안의 주요 버튼은 검정 잉크색·흰 글자·오른쪽 화살표, 최소 52px 높이와 1px 모서리를 사용한다. 밑줄 입력은 투명 배경, 최소 52px 높이, 고정폭 값을 사용한다. 종이 범위에만 본문·보조 문자·오류·비활성·초점 의미 변수를 재정의하고 어두운 후속 화면의 색 역할은 유지한다. 세부 값은 `docs/design-system.md`를 따른다.

## 입장 화면

- 큰 제목은 `HOME / COMING` 두 줄이며 접근 가능한 행사명은 `GDG HOME COMING`이다. 제목의 프로그램 초점과 버튼·링크의 키보드 초점 처리를 유지한다.
- 소개 아래에 절취선을 두고 일시·장소를 인쇄 정보처럼 배치한다. 좁은 화면에서는 일정 줄바꿈과 라벨·값의 세로 배치를 허용한다.
- 일시는 **2026.11.21 15:00 ~ 11.22 04:00**, 장소는 **성수 그린힐드**다. 장소명은 사용자 제공 [네이버 지도](https://naver.me/GMmLF6Ap)에 연결하며 새 탭 안내·외부 링크 표시·최소 44px 터치 영역을 유지한다.
- **발권하기**는 이메일 참가 확인으로 이어지는 주요 버튼 하나다. 입장만으로 명단 확인·추첨·배정을 실행하지 않는다. 기존 티켓 복원은 이메일 확인 뒤 기존 흐름을 따른다.
- 공통 하단 **문의하기**는 [기존 카카오 문의](https://open.kakao.com/o/gvuQCBRi) 텍스트 링크다. 별도 `GDG AIR` 상단 표기·소리 조작·신청 마감·티켓 찾기 버튼을 추가하지 않는다.

## 이메일·닉네임 화면

`CHECK-IN`·`PASSENGER`는 장식 표제로 제공하고 실제 화면 제목은 기존 승인된 한국어 문구를 유지한다. 뒤로 가기, 명시적 입력 라벨, 도움말·오류 연결, 이메일 키보드·자동완성, 로딩·재시도·복원 중 상태와 중복 제출 방지는 기존 계약을 유지한다. 오류와 비활성 상태는 종이 전용 의미색 및 실제 HTML 속성으로 표현한다.

입장·입력의 최대 500px 컨테이너, 검정 바깥 여백, 세로 스크롤을 유지한다. 이번 표현 변경은 기존 어두운 기계식 전광판·금속 발권기·실제 탑승권·출력 및 뜯기 연출을 대체하지 않는다. 확인 모달과 수령 모달도 기존 동작과 각 표면의 역할을 유지한다.

## 대체된 초안

`src/containers/home/assets/airport-night.png`와 `airport-night.webp`는 사용하지 않는 공항 사진 초안이다. 이어서 검토했던 `FlapCell` 기반 랜딩 제목도 현재 입장 화면에서 사용하지 않는다. 실제 추첨 화면의 플립 표현은 계속 사용한다.

## 확인 범위

이 문서 갱신은 현재 컴포넌트·스타일과 승인 기준을 대조해 설명을 수정한 작업이다. 폰트는 공식 Google Fonts HTTP 출처와 OFL 원문을 확인했으며 문서에는 Prettier 포맷을 적용했다. 현재 화면의 빌드·브라우저·대비·실제 기기 검증을 수행했다는 의미가 아니다. 이전 사진·플립 제목 초안의 검사 결과를 현재 종이 화면의 결과로 재사용하지 않는다.
