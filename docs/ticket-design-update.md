# 세로 화면 발권과 탑승권 디자인

2026-10-10 변경. 휴대폰 세로 화면을 유지하면서 상단 슬롯에서 가로형 종이 탑승권이 아래로 출력된다. 회전 단계와 회전 안내를 삭제했다.

## 표현

- 차콜 발권기와 아이보리 종이, 기존 Google 색상 하단 선을 유지한다.
- 항공코드와 승객명으로 정보 위계를 만든다. 승객명은 전체를 줄바꿈하며 잘라내지 않는다.
- 본문 76%와 절취 스텁 24%를 나눈다. 기존 항공편, 날짜, 시간, 게이트, 행사 정보만 표시한다.
- 슬롯과 발권기는 고정한다. 종이만 1.6초 동안 위에서 아래로 이동하며 마지막에 감속한다. 출력 완료 시 같은 DOM을 유지한다.
- 확대와 PNG는 같은 BoardingPass 컴포넌트를 사용한다. 확대의 라벨·도시는 최소 14px, 정보 값은 최소 18px이다. 최종 720px 확대 DOM 측정은 라벨 14.36px, 도시 15.796px, 정보 값 20.104px였다. Escape로 닫은 뒤 초점 복귀도 확인했다.
