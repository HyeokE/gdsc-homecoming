# GDGoC DJU 탑승권 디자인

2026-10-10. 사용자가 승인한 `outputs/gdgoc-dju-boarding-pass-v3.png` 시안을 실제 `BoardingPass` 컴포넌트에 반영했다.

## 표현과 데이터

- 밝은 종이와 검은 고정폭 인쇄 글씨, 작은 Google 4색 개발자 마크, `GDGoC DJU` 브랜드를 사용한다.
- 본권 72%와 절취 부분 28%를 세로 점선으로 나눈다. 큰 공항 코드, 비행기 화살표, 하단 4색 띠를 제거했다.
- 성명, 출발, 도착을 한·영 라벨 옆에 행으로 정렬하고 편명·날짜·탑승시간과 게이트·등급을 아래에 배치한다. 절취 부분에도 동일 데이터를 반복한다.
- 승객명·목적지·공항 코드·게이트는 전달받은 결과를 그대로 사용한다. 시안의 예시 승객명으로 바꾸거나 성과 이름을 추정해 재배열하지 않는다. 긴 이름과 도시는 생략하지 않고 줄바꿈한다.
- 편명 `GDG1121`, 날짜 `21NOV2026`, 시간 `15:00`, `HOMECOMING CLASS`를 유지한다. 좌석 번호는 추가하지 않는다.
- 바코드는 개인정보나 연결 주소를 인코딩하지 않는 장식용 SVG다. QR 이스터에그는 구현하지 않았다.
- 발권 화면, 완성 티켓, 크게 보기, PNG 저장이 같은 컴포넌트를 소비한다. 확대는 1080px 너비로 내부 가로 스크롤을 제공한다.
- 현재 발권기의 왼쪽 슬롯과 오른쪽 출력 애니메이션은 기존 구현을 유지한다.

## 검증

Aside Browser의 실제 Storybook에서 다음을 확인했다.

- 긴 승객명과 `PARIS / CHARLES DE GAULLE`: 320/390/500px 프레임에서 문서 및 티켓 내부 가로 넘침 없음. 티켓 내용 영역은 각각 278×114, 348×142, 458×186px였다.
- 확대: 내용 너비 1078px, 본권 라벨 14.553px, 승객명 25.872px, 내부 정보 넘침 없음.
- 실제 `saveTicketImage`로 390px 프레임에서 PNG 다운로드. 결과 1050×390px를 직접 열어 브랜드·동적 이름·도착지·바코드를 확인했다. 버튼·이메일·주변 화면은 포함되지 않는다.
- 저장 예시: `outputs/gdgoc-dju-ticket-implemented.png`.
- 발권기에서 같은 티켓 렌더링 확인. 기존 애니메이션 타이밍·라우팅은 이번 작업 범위가 아니다.

Storybook의 `컴포넌트/탑승권`에 Desktop, CompactPhone, LongNameAndCity, Expanded, SaveAndEnlarge를 추가했다. 마지막 스토리는 실제 이미지 저장 함수와 확대 모달을 사용하며 참가자 저장소를 변경하지 않는다.
