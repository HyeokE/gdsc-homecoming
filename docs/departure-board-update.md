## 실제 국가판만 이동

처음에는 실제 국가 grapheme 수만큼의 플랩만 중앙에 놓는다. JAPAN은 5칸, USA는 3칸이며 공백도 한 칸이다. 초기 셀 폭은 36–64px이고 총 폭은 화면 안에 제한한다. 설명형 제목, 행사 eyebrow와 초기 대기 문구는 없다.

국가가 정착하면 같은 국가 wrapper가 `departure-country-panel` layoutId로 상단 행의 시간 5칸 다음 국가 열에 이동한다. 이 wrapper는 초기와 최종 모두 실제 glyph만 포함한다. JAPAN의 최종 wrapper도 5칸이며 국가 예약 14칸의 나머지 9개 공백은 matrix 직접 자식으로 최종 자리에 고정된다. 공백이나 다른 행이 국가와 함께 날아가지 않는다. 원본 국가 인덱스를 key로 유지한다.

장비와 배경의 layout morph를 제거하고 국가 노드만 이동한다. 이동판은 overflow visible와 상위 레이어를 사용해 잘리지 않는다. 문자판 반부를 자르는 기존 구조와 rotateX 회전은 보존한다. 국가가 예약 열을 초과하면 실제 값만 추가 행으로 이어지고 공백은 외부 행렬이 채운다.

## 치수와 흐름

전체 판은 4행이며 기본 셀 높이는 30–34px이다. 최종 글자 크기는 실제 셀 폭의 0.9배와 최대 26px로 계산한다. 로컬 DIN Condensed, Arial Narrow와 기존 mono fallback으로 좁은 공항 글자 비례를 사용한다. 한글·emoji도 셀 안에 들어가도록 크기 계산은 같은 방식이다. 얇은 셀 rim, 판 상하 edge와 중앙 힌지만 두고 장식 나사나 새 아이콘을 넣지 않았다.

확인 버튼은 최대 360px로 가운데 배치한다. 기존 문자 회전 일정, 650ms 국가 이동과 확인 조건을 유지하며 모션 감소에서는 최종 결과로 바로 이동한다. 국가 공개부터 휴대폰 가로 안내를 제공하는 요구는 프론트 방향 흐름에서 처리한다. 가로 전광판의 최대 폭은 960px이고 다른 입력 폼의 기존 최대 500px과 구분한다. 발권기의 가로 티켓 출력 변경은 별도 구현이다.

## 검사

표현 소유 파일은 `src/components/DepartureReveal.tsx`, `src/styles/departure-reveal.css`이다. 최종 5열·4행 구현 후 Prettier, 해당 컴포넌트 ESLint와 전체 TypeScript 검사를 통과했다. 변경마다 kill-ai-slop 스캔·코드 판독을 수행했다. 실물 플랩의 서체와 물리적 회전 명암은 의도된 표현이며 분위기 그라데이션이나 글로우를 추가하지 않았다.

이후 실제 가로 방향 흐름, 초기 국가 수, 고정 공백 좌표, 노란 상단 행과 아래 목데이터, 국가 이동과 발권 흐름을 통합 검증한다. 부모·담당자 검토는 사용자의 최종 디자인 수용을 대신하지 않는다.
